# Captura & Cubagem Pro v2

Projeto Android refeito do zero.

## Recursos desta versão
- Cadastro de produtos com foto
- Foto do cartão do fornecedor
- Código, fornecedor, telefone/WeChat e preço
- Quantidade, comprimento, largura, altura e peso
- Cálculo automático de cubagem em m³
- Indicador de ocupação do container até 68 m³
- Catálogo/relatório em PDF com fotos e dados
- Build automático do APK no GitHub Actions
